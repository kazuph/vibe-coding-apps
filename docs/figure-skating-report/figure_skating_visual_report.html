氷上トレーニング：エッジワークの極意

4大ターンの違い、わかりますか？

SVG図形では伝わりにくい「足首の使い方」や「体重移動」も、動画なら一目瞭然です。 特に以下の4つのターンの違いは、ステップシークエンスのレベル獲得に直結します。

スリーターン (3-Turn) カーブと同方向へ回転。最も基本。
ブラケット (Bracket) カーブと逆方向へ回転。「｝」を描く。
ロッカー (Rocker) 同方向回転だが、円の軌道を維持。
カウンター (Counter) 逆方向回転。円の軌道が反転する。
おすすめポイント

この動画は足元のアップ映像があり、スリーターンとブラケットのエッジの切り替え位置の違いが非常にクリアに理解できます。

伝説の「コンパルソリー」を見る

かつて五輪種目だった「コンパルソリー（規定図形）」。氷の上に正確な「8の字」を描くこの地味な練習こそが、トップ選手の滑らかなスケーティングの源流です。

理論のポイント： 「プッシュして進む」のではなく、「重心を傾けて（リーン）、エッジの曲線に乗ることで勝手に進む」感覚を養います。これが省エネでスピードの落ちないスケーティングを生みます。
