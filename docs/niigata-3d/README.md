# 新潟駅 3Dマップ（完成予想 2027）

改修中の新潟駅（万代広場は 2027年春に全面供用予定）の完成形と、万代島（朱鷺メッセ）・白山（りゅーとぴあ）周辺を three.js で表示するマップです。

## データの出どころ

| 要素 | ソース | 確度 |
|---|---|---|
| 既存建物 約38,000棟（外形・高さ・主要部の屋根形状） | 国土交通省 Project PLATEAU 新潟市 2023年度（CityGML, LOD1/LOD2） | 実測 |
| 道路・川・緑地・鉄道・橋の外形 | OpenStreetMap（2026年9月取得） | 実測・トレース |
| 竣工済みの万代広場の上屋・デッキ・トイレ・交番 | OSM の `building=roof` ほかの外形 | トレース |
| 工事中の中央エリア（築山ステージ・北側上屋など） | 新潟市「万代広場の整備」エリア区分図、整備計画（令和2年10月）p.18 | 公式図を座標変換 |
| アイコニックタワー新潟ステーション | OSM の外形 + 公表高さ 103.85m | 公表値 |
| 上屋・デッキ・大屋根・高架の高さ | 公表されていない → 推定値（画面上で「推定」と表示） | 推定 |

PLATEAU 2023年度の計測時点では、万代広場の一帯は工事中でした。当時の仮設・工事中の構造物のうち、2026年の OSM に対応する建物がないもの（23棟）は、計画モデルに置き換えています（`plan.js` の `HIDE_IDS`）。画面左下の「完成予想 2027」をオフにすると、計測当時の状態に切り替わります。このとき、万代広場の計画要素・万代口東地区の敷地に加えて、計測後に竣工したため補ったアイコニックタワー新潟ステーションも隠れます。撤去済みの23棟は、クリックすると実測高さを表示します。

## 公表資料で確認できなかった値（推定値で代用）

- 高架のレール面の高さ（12.5〜13.5m と推定）
- 万代広場の上屋の高さ（設計条件「歩行空間 3.2m以上・バス車道 4.7m以上」から 5.2m と推定）、円形ユニットの径
- ペデストリアンデッキ中央大屋根の寸法と高さ
- 万代口東地区（JR東日本、2028年夏開業予定）の棟の配置 → 建物は置かず、敷地の輪郭だけを表示

## データの再生成（`tools/`）

1. `rzip.py` で PLATEAU の CityGML zip（約4.3GB）から、必要な3次メッシュ（5639-60-82〜5639-70-25）の `bldg` だけを HTTP Range で取り出します。
2. `parse.py` で OSM API `/map` のタイルと信濃川のリレーションを読み込みます。
3. `conv.py` → `export.py` で `data/city.bin` を作ります（LOD1 は外形+高さ、LOD2 は三角形。0.25m 単位の int16）。
4. `osmexport.py` で `data/osm.json` を作ります。

座標系は、原点が北緯37.9125・東経139.0615（新潟駅付近）の平面直交（x=東, z=南, m）です。
