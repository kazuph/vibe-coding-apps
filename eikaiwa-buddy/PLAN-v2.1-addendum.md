# eikaiwa-buddy v2.1 追補設計（ユーザー実体験フィードバック反映）

## 依頼内容（2026-07-08 マスター原文要約）

1. チップ（選択肢）生成待ちで毎回時間がかかる。**常に自由入力も受け付ける**設計に。プロフィールや**SNS投稿のコピペで一括コンテキスト注入**できるボックスも必要
2. **担当AIがどのモデルか画面上に明示**
3. 運営者向けに**API利用料金をちゃんと表示**（個人アプリなので隠さず出す）
4. サイドバーの「今日は何を一緒に作る？」が**常に出続けるのはUX改善余地**。選択後は消す
5. プロフィール入力が最下部の小さい入力欄でいいのか**迷う**。自然に入力できるUIに
6. **ChatGPTのような新規チャット開始UI**（サイドバーで簡易実装でOK。会話履歴はD1で全管理されている前提）
7. **フォームは複数行入力**対応

- **サイドバー**: ①「＋ 新しく作る」ボタン ②セッション履歴リスト（topic+日付、タップで切替・復元、activeハイライト）③「Kaiに自分のことを教える」④設定。**トピックボタン群と小入力欄はサイドバーから撤去**

- **トピックピッカー**: 新規/空セッションの最初にだけ、メインストリーム内のカードとして表示。**選択 or 自由入力開始で消える**（再表示は「＋新しく作る」から）

## 各要件の設計

### 1. 常時自由入力（チップは近道、関門にしない）
- メイン下部の入力欄は**textarea（複数行、自動高さ、Enter送信/Shift+Enter改行、モバイルは送信ボタン）**
- interview/draft/variantsどのフェーズでも入力可能。チップは入力欄の直上に「タップでそのまま送れるショートカット」として表示するだけ
- チップ生成待ちで入力をブロックしない（送信中のみ二重送信防止でdisable）
- トピック未選択状態で自由入力が来たら、それをトピック/文脈として扱いインタビュー開始（ボタンを押させない導線もあり）

### 2. コンテキスト一括注入「Kaiに自分のことを教える」
- サイドバーから開くモーダル（or 専用カード）。**大きなtextarea**に自由貼り付け（プロフィール、SNS投稿、自己紹介文、何でも）
- 送信すると `gemini-3.1-flash-lite` で fact抽出 → **抽出結果（key=value一覧）をプレビュー表示→「保存」で確定**（勝手に保存しない、透明性重視）
- 保存済みfactの一覧表示・個別削除・手動追加もこのモーダルで（user_contextのCRUD）
- API: `POST /api/context/ingest`（text→facts案）, `GET/PUT/DELETE /api/context`

### 3. モデル明示
- 各APIレスポンスに `model` フィールドを含め、UIで表示:
  - Kaiの各発言・ドラフト・変種カードに小さなタグ（例: `gemini-3.5-flash`）
  - 発音評価結果にも同様（例: `評価: gemini-3.5-flash`）
  - fact抽出・チップ等の軽量処理は `gemini-3.1-flash-lite` タグ
- ヘッダーのアプリ名下に既定モデルを常時表示（`Gemini-powered (3.5-flash / 3.1-flash-lite)`）

### 4. API利用料金の可視化（運営者ビュー）
- **全Gemini呼び出しで usageMetadata（promptTokenCount/candidatesTokenCount等）をD1へ記録**:
```sql
CREATE TABLE api_usage (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  kind TEXT NOT NULL,          -- chat|variants|eval|tts|context_ingest
  model TEXT NOT NULL,
  input_tokens INTEGER NOT NULL DEFAULT 0,
  output_tokens INTEGER NOT NULL DEFAULT 0,
  audio_input_tokens INTEGER NOT NULL DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now'))
);
```
- 単価表は定数（2026-07-08時点・従量課金の定価。出典: ai.google.dev/gemini-api/docs/pricing系）:
  - `gemini-3.5-flash`: input $1.50/1M（音声等マルチモーダル入力も同額）, output $9.00/1M
  - `gemini-3.1-flash-lite`: text input $0.25/1M, **audio input $0.50/1M**, output $1.50/1M
  - `gemini-3.1-flash-tts`: 実装時に公式pricingページの現行値を確認して定数化。**取れない場合は捏造せず「TTS単価未設定」とUIに明示**
- UI: 右カラムに「API利用料金」カード → 今日 / 今月 / 累計（USD）。タップで内訳（モデル別・種別別テーブル）
- 注記表示: 「従量課金定価での換算値。無料枠適用時の実請求とは異なる場合があります」

### 5. セッション管理（ChatGPTライク・簡易版）
- `GET /api/sessions`（一覧: id, topic/タイトル, 最終更新, スコア概要）
- `POST /api/session/new`（現セッションはそのまま残して新規作成・切替）
- セッションタップで切替（chat_history・script・phase全部復元＝既存復元機構を流用）
- タイトルはtopic（なければ最初の入力の先頭20字）

## 実装フェーズ
- **V21a**: レイアウト刷新（サイドバー: 新規作成+セッション一覧 / メイン: ストリーム+下部複数行入力 / トピックピッカーのライフサイクル修正）
- **V21b**: コンテキスト注入モーダル（ingest→プレビュー→保存、user_context CRUD）
- **V21c**: モデルタグ表示 + api_usage記録 + 料金カード
- **V21d**: E2E更新（新規セッション作成→自由入力だけでドラフト到達 / コンテキスト注入→登録済み反映 / 料金カード表示）+ viewportスクショ + REPORT更新

## 受け入れ条件
1. チップが出ていなくても・生成中でも、いつでも複数行自由入力で会話を進められる
2. プロフィール/SNS投稿をコピペ→抽出プレビュー→保存→以後のKai発話に「登録済み」として反映される
3. トピックピッカーは新規セッションの最初だけ表示され、開始後は消える
4. サイドバーで新規チャット作成と過去セッション切替ができ、切替後も完全復元される
5. すべてのAI応答に使用モデルが表示される
6. 料金カードに今日/今月/累計コスト（USD）が表示され、内訳がモデル別に見られる。数値はapi_usageの実トークン数×定価から計算（捏造・概算表示禁止。TTS単価不明時はその旨表示）
7. 既存の受け入れ条件（承認前英語ゼロ・実Gemini E2E・モデルallowlist・fallback偽装禁止）を維持
8. build/lint/vitest/E2E緑 + viewportスクショ + REPORT更新（yunomi不要、ユーザー直接体験で判定）
