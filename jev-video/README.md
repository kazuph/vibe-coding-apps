# Jev 動画図解

指定動画 `MN9dGgmLyso` を全編を一度解析し、再生に合わせて日本語の関係図を表示するローカルツールです。

- YouTubeの実際の英語字幕を文単位にまとめます。
- Chrome内蔵Translatorで日本語に翻訳します。翻訳用APIキーは不要です。
- **Jev 1.13.0** が日本語から意味のある概念、話のカテゴリ、既存概念との同一性、概念間の関係を判定します。名詞候補の抽出にはkuromojiを使います。
- Cytoscape.jsがその結果を関係図として表示します。概念を押すと根拠となる発言の一覧を開き、そこから動画の場面に移動できます。カード内に時刻は表示しません。
- 同じ概念・同じ関係への再言及はノードや線を追加せず、根拠だけを増やします。巻き戻すと未来の概念・関係・根拠が消え、先に進めると再表示されます。解析済みの文章はディスクに保存され、再解析しません。

Jevは翻訳・音声認識・自由文生成モデルではありません。字幕から取り出した文章を図にする構成です。日本語の要約文をJevが創作したと表示することはありません。

## 作者が編集したタイムスタンプ付き図解

`http://localhost:<ポート>/story` を開きます。Codexが全編の英語自動字幕497文を読み、8つの話題・54か所の日本語説明と図の更新を事前編集した比較用ビューです。`/story?t=1115` は検証の話から開きます。

- 全話題は1枚の連続した図に累積します。再生や話題の変更では座標・倍率・カメラを動かしません。カテゴリ間も意味のある関係でつなぎます。
- バー、前後の説明ボタン、動画再生に連動します。カテゴリ名を押すと、その場所へ移動できます。「全体を見る」で俯瞰し、「読める大きさ」で等倍へ戻せます。時刻はカードの外に表示します。
- 作成済みの図は `public/story.json` に保存済みです。再生・移動・リロードでJevや翻訳APIは呼びません。再生位置はブラウザに保存します。
- 根拠ボタンで実際の英語字幕を確認できます。日本語は逐語訳ではなく説明のための要約です。固有名詞は自動字幕の誤認識が残るため、確定できない名前に依存しない図にしています。
- 動画は消音・停止状態から始まります。狭い画面でも同じ図をドラッグ・拡大縮小して閲覧します。
- 編集元は `story-source.mjs`。字幕を取り込んだ環境で `node build-story.mjs` を実行すると、引用箇所の終了時刻から表示時刻を再生成します。
- 旧Jev版は `/` に残しています。以下の解析操作は旧Jev版にのみ適用されます。

検証: `node --test tests/story.test.mjs` と `BASE_URL=http://localhost:<ポート> npx playwright test tests/e2e/story.spec.ts`。

## 起動

Node.js 22以降と、Translator APIを利用できるデスクトップChromeが必要です。

```sh
cd jev-video
npm ci --workspaces=false
# .env に JEV_API_KEY=... を設定する（Git管理外）
npm start
```

表示された `http://localhost:...` をChromeで開きます。`PORT`を指定すると固定ポートを利用できます。

1. 「全編を一度だけ解析」を押します。Chromeが翻訳モデルを準備し、全編の未解析の文章だけをJevで順番に処理します。解析中は図を表示しません。
2. 「全編解析済み」になったら「再生」を押します。発言に合わせて保存済みの概念・関係を表示し、根拠を増やします。初期状態は消音です。再生・シーク・再読込ではJevを呼びません。
3. 図を画面いっぱいに表示し、初期倍率は文字が16pxになる等倍です。「全体を表示」は概要確認用、「読める大きさ」は等倍への復帰です。カテゴリや概念を選ぶと、座標を変えずにその場所へ移動します。選択した概念の直接の関係を強調し、その他の線を薄くします。動画と字幕はヘッダーの「動画・字幕を開く」で表示し、再生操作とシークバーは下部に常設します。概念の根拠はクリックしたときだけ開きます。シークバー、YouTubeプレーヤー、概念の根拠欄、字幕のいずれからも場面を移動できます。
4. 最後へ飛ばしても解析は発生しません。全編の完成図を先に配置し、再生中は表示だけを切り替えます。既存の概念・カテゴリ・カメラは自動で動かしません。配置はブラウザに保存され、再読込でも再利用します。カードが重なる位置だけは初期配置時に空いている場所へ退避させます。
5. 図は「技術・ツール」「品質・検証」「開発フロー」「組織・役割」「目標・成果」「考え方・原則」「課題・制約」でまとめます。カテゴリはJevが選び、同じ概念が再登場したときも位置を分散させません。
6. 「全編解析を停止」でバッチを止められます。実行中のJevリクエストは完了して保存します。「残りの全編解析を再開」で続きだけを実行します。ページを閉じたときも保存済みの文章は再解析しません。

## 字幕

今回の作業環境には、対象動画の全編の英語自動字幕を通常のYouTube画面から取得済みです。字幕本文は公開リポジトリに含めません。新規チェックアウトでは、対象動画の時刻付き英語字幕を次の形式で保存して取り込みます。

```text
YouTube transcript
Video ID: MN9dGgmLyso
Language: en

[0:00] So, hello folks. I've got another treat
[0:02] for you today.
```

```sh
node import-transcript.mjs /absolute/path/to/transcript.txt
npm start
```

YouTubeから取得した同じ動画の英語`json3`字幕も取り込めます。例えば手元のyt-dlpで取得する場合：

```sh
yt-dlp --skip-download --ignore-no-formats-error --write-auto-subs --sub-langs en --sub-format json3 -o '%(id)s.%(ext)s' 'https://www.youtube.com/watch?v=MN9dGgmLyso'
node import-transcript.mjs MN9dGgmLyso.en.json3
```

YouTubeがHTTP 429を返すときは取得を繰り返さず、通常のYouTube画面から文字起こしを取得します。起動中に字幕を変えた場合はサーバーの再起動が必要です。

## 検証

```sh
npm run check
node --env-file=.env --test tests/concepts.live.test.mjs
BASE_URL=http://localhost:<起動時のポート> npm run test:e2e
```

E2Eはインストール済みChromeを使い、実際の字幕・Translator・Jev・YouTubeを操作します。モックもブラウザの追加インストールもありません。APIの利用料金は実際に発生します。試験用の受入時刻はテスト中だけの値です。

## データと制約

- APIキーはサーバーの`.env`だけに置き、画面には送りません。サーバーはループバックだけで待ち受け、別サイトからの解析要求を拒否します。
- 字幕は`data/`、翻訳とJevの結果は`.data/`に保存します。どちらもGit管理外です。
- 字幕変更時には内容のハッシュを変えて、以前の字幕の解析結果と混ぜません。
- 図の意味づけはJevの判定であり、事実の保証ではありません。クリックすると原文・日本語訳・モデル名・処理時間を確認できます。
- 字幕の時刻精度は秒単位です。最後の字幕断片の次の時刻に、その文の図を表示します。
- JevのChoiceは最大255候補のため、既存概念を254件ずつ照合します。冒頭の概念を候補から落とさず全履歴を照合します。
- 現在は指定された配信アーカイブを対象にしています。未字幕化の生放送の音声認識はありません。
- Chrome内蔵翻訳はモバイル非対応です。解析済みの図は再読込後も表示できます。
