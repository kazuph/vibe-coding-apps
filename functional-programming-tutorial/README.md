# 関数型プログラミング完全ガイド

MoonBit・Haskell・Elixir・TypeScript/Effect で学ぶカリー化からモナドまで。

## 概要

関数型プログラミングの「難しい」と言われる概念を、4つの異なる言語で比較しながら学ぶ教材です。

## 対象言語

| 言語 | 特徴 |
|---|---|
| **MoonBit** | Rust風の文法、WASMを出力、実用的な関数型 |
| **Haskell** | 純粋関数型の王道、理論的な美しさ |
| **Elixir** | 実用的な関数型、並行処理が得意 |
| **TypeScript + Effect** | 既存のJSエコシステム、型安全な関数型 |

## 学べる内容

1. 純粋関数と不変性
2. 高階関数（map, filter, reduce）
3. カリー化と部分適用
4. 代数的データ型とパターンマッチング
5. ファンクター
6. アプリカティブファンクター
7. モナド
8. モナド変換子
9. エフェクトシステム

## 使い方

`index.html` をブラウザで開いてください。
